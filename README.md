# Low-Latency Telemetry & Kernel Monitoring
This repository focuses on low-level Linux kernel telemetry, eBPF infrastructure, and high-performance network monitoring.

## Core Components (Planned)
* **ebpf-parsers/**: C code running inside the Linux kernel space for fast, lock-free event filtering.
* **user-space-consumers/**: Python and Modern C++ applications to process, aggregate, and visualize high-throughput system metrics.

## Future Master Modules Integrated Here
* Network Forensics (Albstadt-Sigmaringen University)
* Incident Response & Infrastructure Monitoring
